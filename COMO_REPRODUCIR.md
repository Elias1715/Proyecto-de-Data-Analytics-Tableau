# Cómo reproducir el proyecto

## 1. Abrir el workbook

Abrir:

`Analisis_Ventas_Portfolio_FINAL.twb`

con Tableau Desktop.

## 2. Reconectar el Excel

Si Tableau informa que no encuentra la fuente, seleccionar el Excel `.xlsm` utilizado durante el proyecto.

Es el mismo dataset trabajado anteriormente; solamente cambió el nombre del archivo por motivos relacionados con macros.

## 3. Verificar hojas

El workbook contiene:

- Detalle de Ventas
- Evolución de Facturación
- Facturación por Producto
- Facturación por Vendedor
- Facturación vs Ganancia por Año
- KPIS

## 4. Verificar Dashboard principal

Abrir:

`ANÁLISIS DE VENTAS`

Comprobar:

- KPIs
- Producto
- Vendedor
- Comparación anual
- Evolución temporal
- Botón de detalle

## 5. Verificar navegación

Desde `ANÁLISIS DE VENTAS`:

`Ver detalle de ventas`

Desde `DETALLE DE VENTAS`:

`← Volver al análisis`

## 6. Publicación en GitHub

Crear un repositorio, por ejemplo:

`analisis-ventas-tableau`

Subir:

- `Analisis_Ventas_Portfolio_FINAL.twb`
- `README.md`
- `INFORME_PROYECTO.md`
- `CAMBIOS_PROYECTO_FINAL.md`
- `INSIGHTS_Y_CONCLUSIONES.md`
- `COMO_REPRODUCIR.md`
- Carpeta `datos/`

Agregar también el Excel fuente si se desea que el proyecto sea reproducible directamente desde el repositorio.
